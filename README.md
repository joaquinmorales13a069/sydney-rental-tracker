# sydney-rental-tracker
This project loads Sydney's rental data available from September 2023 to September 2026. The goal is to create a local pipeline that loads, clean and analyses the dataframe to answer several use case questions.

## Questions to answer:
1. What is the median weekly rent in Greater Sydney each month, and how has it changed since January 2023?
2. Which 10 postcodes had the largest rent increase from 2023 to 2025?
3. How does median rent differ by dwelling type and number of bedrooms?
4. Which postcodes have the most new leases each month, and is that changing?
5. What is the year on year change in median rent for each region?
6. How does Burwood (2134) and the Inner West compare with the Sydney median?
